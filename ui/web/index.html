      Each hook is a point where the loader attaches to the game. Turn one off to stop its events. This can help you find a faulty hook. Click a module name to toggle all its hooks.

      Launch

      The launcher hides while Sacred is running and returns when you quit the game.

      Mod repositories

      A mod repository is a Git repository with sacred.mods.repository.json in its root. The launcher reads this file and its images without cloning the repository. Downloaded mods do not run until you press Play.

        Get Java

        Mods run in a Java virtual machine beside the game. Without a JDK, Sacred still launches but no mods load. The launcher downloads the JDK to launcher\java in the game folder. It does not install anything elsewhere, and deleting the game folder also removes the JDK.

        Update Sacred Mod Loader

        The whole loader travels inside this one file, so the update replaces it and starts the new one. Your mods, your settings and any Java the launcher downloaded stay where they are.
