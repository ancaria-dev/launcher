      Each hook is a point where the loader attaches to the game. Turn a hook off to stop its events, for example to track down a faulty one. Click a module name to switch all its hooks.

      Launch

      The launcher hides while Sacred is running and returns when you quit the game.

      Mod repositories

      A mod repository is a Git repository with sacred.mods.repository.json at its root. The launcher reads that file and its images without cloning anything. Downloaded mods don’t run until you press Play.

        Get Java

        Mods run in Java, next to the game. Without a JDK, Sacred still starts, but no mods load. The launcher puts the JDK in launcher\java inside the game folder and nowhere else, so deleting the game folder removes it too.

        Different game build

        Download pureHD fetches the matching build from ancaria.dev and installs it. You can also find a copy yourself. Your original game executable stays as it is: the launcher adds pureHD.exe and pHD.dll next to it and starts pureHD.exe from then on. It first moves any older copy of those files to launcher\purehd-backup.

        Why pureHD? It fixes a long list of bugs in the original game, keeps the balance and the feel of Sacred, and adds only what’s truly useful. That’s why the loader builds on it.

        Update Sacred Mod Loader

        The whole loader lives in this one file. The update replaces it and starts the new version. Your mods, settings, and downloaded Java stay where they are.
